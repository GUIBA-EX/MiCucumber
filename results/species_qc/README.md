# MiCucumber 参考序列清理与去重

本目录是用于重新评估引物的参考面板。每个可确认物种最多保留一条代表序列；原始序列库没有删除或覆盖。

输入 1848 条；保留 **174 个具名物种、每种一条**。

## 序列处理

1. 对照原始序列核查旧比对的方向和碱基组成；旧比对中缺失的片段从原始序列恢复。为保留的代表序列重新进行 MAFFT 7.526 多序列比对，并核对去除 gap 后的序列与重建输入逐条一致。
2. 排除无法对应原始序列、有效碱基少于 100、模糊碱基超过 5%、或没有任何可评价窗口的记录；未定种、无法可靠核对分类的记录另列。相同物种的其他合格记录作为重复记录排除。
3. 按完整可评价窗口数量、模糊碱基数量、参考位点覆盖情况等排序选择代表，不使用现有引物匹配结果作为选择标准。
4. 某长度的两个引物窗口均需跨越对应位置、各含至少 90% 的参考位点数的 A/C/G/T，且窗口无非 A/C/G/T 的模糊字符，才列入该长度的可评价集合。允许比对 gap；是否匹配引物另行评价。
