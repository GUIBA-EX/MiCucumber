# MIDORI2 specificity

MIDORI2 GB273 SINTAX unique-sequence lrRNA and CO1 files were downloaded on 12 November 2026. Each species label was represented by its longest sequence in the relevant file. The input manifest records the official archive paths and SHA-256 hashes. Full-length linked Cutadapt 5.0 primer matches allow 0, 1 or 2 mismatches per oligonucleotide without indels. Background counts are predicted mitochondrial eukaryotic reference matches.

`midori_summary.csv` gives target and non-target species counts. `midori_hits.csv` lists species and database taxonomy by assay and threshold. These species are classified using the labels in MIDORI2. The database does not include bacterial ribosomal references.
