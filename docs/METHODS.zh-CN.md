# 方法说明

## 1. 历史基线与冻结输入

按README给出的工作簿单元格提取v4和旧决定版，不能从下游文件名推断引物版本。复用MiStar冻结参考库，按accession跨输入去重并区分海参与背景。目标中1,686条有注释、160条仅标题支持。背景包含海星1,955、蛇尾1,736、海胆1,401、海百合269及其他后生动物239条。

## 2. 比对与共同面板

MAFFT 7.526比对116条完整无模糊碱基序列，再以`--addfragments --keeplength`加入目标片段，参考坐标使用AB525437.1。共同可比较区间保留149个双名格式名称标签及347个标签内唯一单倍型。比对用于判定可比较性；结合与产物扫描在原始序列双链进行，不允许结合位点内插缺。Aspidochirotida等沿用源记录历史分类，未更新为统一现代分类。

## 3. 候选发现与特异性优先筛选

初始搜索产生1,366条寡核苷酸、81,352个配对，随后局部细化v4。四个同源位置的补覆盖搜索考虑684条寡核苷酸及全部28,682种F/R组合，结合IUPAC简并、Tm相容性及结构筛选。有限多起点贪心搜索最多选择4个组分配对，不保证全局最优。分别PCR仅合并指定配对；单管混合则评估所有F/R交叉组合。

WC模型允许每条引物≤2、≤3或≤4个错配；GT≤2沿用MiStar的G:T容忍变换并允许至多2个其他错配，是敏感性模型而非完整聚合酶模型。背景两结合位点间内部距离0–1,000 nt；目标总产物150–500 bp，内部序列至少50 nt。含模糊结合碱基的记录单列。每方案WC≤3及GT≤2分别不超过5条背景记录，是将“少量”操作化的分析约束，不是实验丰度阈值。

## 4. Apodida补充

从17条源Apodida记录的同源位置提取真实F/R窗口，得到37个不同候选配对。本轮允许并标注AAAA，因为部分真实结合序列含该基序。要求发卡Tm<55°C、F/R Tm差≤5°C；在背景并集约束内优先补Apodida，再增加总覆盖。保留13条方案内追加配对，v4opt/S/M/L最终分别为7/7/6/9个独立PCR。追加配对二聚体在50 nM情景下均低于55°C；不支持将新增集合直接混成单管。

## 5. 热力学与计算复核

Primer3-py 2.3.1参数：单价盐50 mM、Mg²⁺ 1.5 mM、dNTP 0.6 mM。第一轮单对/混合池考虑具体变体50 nM及每方向总200 nM按寡核苷酸与简并度分配两种情景，池内重复变体浓度相加。不等浓度二聚体用较大浓度作为Primer3标量输入，仅为近似敏感性分析，不是PCR配方。第一轮混合池评估所有具体同方向与反方向序列相互作用；Apodida追加只完成50 nM配对检查，尚无全池及浓度网格验证。

独立C++程序逐位置穷举结合窗口，与Python结果核对第一轮目标命中、产物长度和背景计数，共通过386,492项检查。追加配对使用该穷举程序，但未完成第二实现的交叉核对。这些验证针对计算一致性，不代表实验准确性。

## 6. 剩余问题

冻结数据库采样不完整，发现和评估未分离；未提供重新下载、同物异名统一、外部验证、湿实验敏感性/特异性或最终PCR条件。v4opt与M仍漏掉共同面板4条Apodida中的2条，S漏1条。L覆盖4条不意味着覆盖全目。报告允许错配覆盖时，应同时保留完全匹配覆盖和更宽松错配条件下的背景风险。
