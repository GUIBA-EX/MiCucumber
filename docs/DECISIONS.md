# Retention decisions / 保留决策

本页原有D方案及百分比对应更新前的冻结基线；新的分类群覆盖以[分层统计](TAXONOMIC_COVERAGE.md)为准。/ Original D assays and percentages on this page describe the frozen pre-update baseline; current taxonomic breadth uses the [hierarchical summary](TAXONOMIC_COVERAGE.md).


按奥卡姆剃刀原则，S–XL每个长度仅保留一个正式D方案：SD采用低简并增强（2/8），MD采用严格背景档（64/4），LD采用覆盖增强（32/1），XLD保留原方案（2/1）。SD更激进档、MD 128/4档和XLD小增益档不进入正式序列。普通单对及S-original不变，A/B已重新选配，每组四套F/R起止坐标完全相同。这是基于收益与复杂度的人工取舍，不是预设统计阈值或已验证PCR最优条件。

Following Occam’s razor, retain one D portfolio per S–XL length: SD with modest degeneracy (2/8), MD under the strict background gate (64/4), LD for its coverage gain (32/1), and unchanged XLD (2/1). More aggressive SD, MD 128/4 and marginal-gain XLD variants remain comparisons. Ordinary single pairs and S-original remain unchanged; A/B have since been re-selected; all four variants in each length share identical F/R start/end coordinates. This is an explicit benefit–complexity judgment, not a preregistered threshold or experimentally established PCR optimum.
