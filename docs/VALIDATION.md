# Validation / 验证

Current sequences, coordinates, degeneracy, target and non-target hit sets, D-primer thermodynamics, base diagrams and bilingual links are checked by `python3 scripts/check_species_release.py`. Results use the same one-reference-per-species panel; algorithmic agreement does not replace experimental validation.

当前引物的序列、坐标、简并度、目标与非目标命中集合、D 引物热力学、碱基图和双语链接使用上述脚本检查。结果使用相同的每物种单条参考面板；算法一致不等同于实验验证。
