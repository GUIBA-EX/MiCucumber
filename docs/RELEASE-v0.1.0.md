# MiCucumber v0.1.0 — computational candidates / 计算候选版

English and Chinese documentation of historical MiCucumber baselines, four optimized length series, and Apodida-focused same-locus additions. Includes complete latest independent-PCR pair tables, frozen reference inputs, background-hit records, thermodynamic results, and an executable revalidation entrypoint.

提供中英双语流程与结果：历史MiCucumber基线、四个长度系列、Apodida同位置补覆盖。包含最新完整独立PCR配对表、冻结参考输入、非目标记录、热力学结果及可运行复核入口。

Latest overall coverage: v4opt 92.51%, S 70.70%, M 79.48%, L 66.76%. Apodida common-panel coverage: 2/4, 3/4, 2/4, 4/4 respectively. These figures are discovery-set computational predictions, not experimentally measured sensitivity. Added pairs must be run separately; mixing supplemented sets is not validated.

最新总覆盖率：v4opt 92.51%、S 70.70%、M 79.48%、L 66.76%；共同面板Apodida分别覆盖2/4、3/4、2/4、4/4。这些是发现集内的计算预测，并非实验敏感性。追加配对按独立PCR使用，尚未验证新增集合混合。

No wet-lab validation or final PCR recipe is claimed. This prerelease is suitable for method review and planning experimental validation.

本预发布版本供方法审阅与实验验证准备，不宣称已完成湿实验或确定最终PCR条件。
